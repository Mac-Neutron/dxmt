The D3D12 headers of the native build (`d3d12.h`, `d3d12sdklayers.h`, `d3d12shader.h`): mingw-w64's, generated by
WIDL 11.12 from Wine's IDL, copied from the llvm-mingw MacNeutron's PE build uses
(`generic-w64-mingw32/include`, the toolchain `dxmt/pins` names). They come before `../directx` (the
mingw-directx-headers submodule, WIDL 7.7, older than DXMT's D3D12) and follow that toolchain: a new llvm-mingw means
copying them again, or the native and PE builds see different interfaces.
